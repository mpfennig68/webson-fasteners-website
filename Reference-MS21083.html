// PART IDENTIFICATION

A low-height nut with a nonmetallic insert

MS21083 identifies low-height self-locking hex nuts with a nonmetallic insert. The insert is a distinct locking construction from an all-metal locknut. Keep the specified material, thread and nut envelope in the requirement.

Do not select an alternate from thread size alone. The assembly’s operating conditions and the controlling drawing determine the acceptable locking design.

// PART-NUMBER EXAMPLES

Preserve the material code and size notation

In the selected records, N identifies cadmium-plated steel and C identifies passivated corrosion-resistant steel. MS21083N3 is a 10-32 selection, MS21083N12 is 3/4-16 and MS21083N16 is 1-12. MS21083C08 uses an 8-32 thread.

Keep the complete designation. The 08 and 3 size codes are distinct; they should not be read as ordinary fractions or carried across to a different series.
