// LENGTH CONVENTION

Measure the correct length

Length L is measured from the bearing surface beneath the head to the tip. The length column preserves the decimal reference values in the reviewed drawing, including 0.12, 0.19 and 0.62. Total head height O is a separate axial measurement and is not included in L. Use the governing issue for length tolerances and full thread-length requirements.

// ORDERING EXAMPLES

Read the part number within its family

MS35266-17 identifies a 4-48 screw with a 0.50-inch under-head reference length. MS35266-63 is a 10-32 by 0.50-inch reference. Although the selected dash-number layout matches MS35265, the thread pitches differ.

// MATERIAL AND CONFIGURATION

Preserve the finish and configuration

The reviewed revision C specifies carbon steel with cadmium plating to QQ-P-416, Type II, Class 3. Its part-number format is the basic MS number plus the dash number. The drilled hole is approximately perpendicular to the slot; the reviewed notes permit it to break through the bottom of the slot. Head drilling does not change the under-head length convention.
