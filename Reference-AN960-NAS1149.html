// PART-NUMBER EXAMPLES

Preserve the thickness and full size code

AN960 uses L to identify the light series. Keep material, size and thickness notation together.

NAS1149CN416R references a #4 size and 0.016-inch thickness. NAS1149D0432J references a 1/4-inch size and 0.032-inch thickness. The N and leading zero are significant.

// PART-NUMBER REVIEW

Do not convert the prefix alone

A full washer designation carries more information than the document family. Size, thickness, material and finish must survive a conversion. Use the actual notice table and its notes rather than inferring the new designation from a similar-looking number.

The stocked tables identify separate selections; their row order is not a cross-reference pairing.
