// PART IDENTIFICATION

Coarse thread and a hex socket

MS16995 identifies hexagon-socket-head cap screws in corrosion-resistant steel with UNC-3A threads. Head clearance, thread class and under-head length are separate parts of the requirement.

// PART-NUMBER EXAMPLES

Read the dash number within this series

MS16995-17 is a 6-32 by 3/8-inch selection. MS16995-52 is a 1/4-20 by 1-inch selection. The dash number is a table reference, not a universal length code.

For the selected stocked parts, B identifies black oxide; an unsuffixed entry identifies passivated CRES. MS16995-17B and MS16995-17 therefore preserve different finish requirements.

// RELATED SERIES

Keep UNC and UNF selections distinct

MS16996 is the related fine-thread stainless family. A corresponding dash number in another series may identify a different thread and length.

// STANDARD STATUS

Legacy document reference

The MS16995 document was canceled on June 30, 1998 and names NASM16995 as its successor. Keep the designation and issue required by your drawing. Document succession alone does not approve a changed ordering configuration.
