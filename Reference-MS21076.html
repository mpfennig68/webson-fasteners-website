// PART IDENTIFICATION

Low height and reduced rivet spacing

MS21076 identifies self-locking, two-lug floating nutplates in corrosion-resistant steel, with reduced rivet spacing and a low-height envelope. The attachment dimensions and nut construction should be checked together.

// PART-NUMBER DETAILS

Read L, 08 and N together

For MS21076L08N, L identifies the dry-film-lubricated configuration, 08 references the 8-32 UNJC-3B thread, and N identifies the version without eyelets. The selected configuration uses passivated A286.

Preserve the full callout. A silver-plated configuration uses a different finish identifier in the reviewed legacy drawing.

// STANDARD STATUS

MS21076 and NASM21076

The legacy MS21076 document was canceled on February 7, 2000 and names NASM21076 as its successor. Submit the part designation and issue required by your drawing; document succession alone does not approve a substitution.
