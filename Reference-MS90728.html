// PART IDENTIFICATION

Identify the grade, thread and finish

MS90728 identifies alloy-steel Grade 8 hexagon-head cap screws with UNC-2A threads. The reviewed issue specifies zinc coated parts. The table covers 97 selected references across 1/4, 5/16, 3/8, 1/2, 5/8 and 3/4-inch diameters, with listed under-head lengths through 3.000 inches. The 7/16 and 9/16-inch columns marked inactive for new design in the reviewed drawing are omitted. The reviewed issue states that this standard is not intended for aerospace applications.

Head across-flats width and axial head height are minimum–maximum drawing limits in inches. Length values preserve the reviewed table’s decimal references, including 0.438 and 0.562; they do not add acceptance tolerances. Across-flats limits describe the screw head, not the tolerance of a wrench or socket.

// MEASUREMENT GUIDE

Measure under-head length and head dimensions

Length L runs from the bearing surface beneath the head to the tip. H is the axial head height; F is the width between opposite hex faces. The head is outside the under-head length measurement.

Thread length is a separate requirement. The reviewed issue uses a minimum rule of twice the nominal diameter plus 1/4 inch, with a positive allowance and separate provisions for screws too short to provide that thread length. Use the full governing issue for those limits. A listed screw length is not a fixed grip length or a claim that the screw is fully threaded.

// ORDERING EXAMPLES

Read the complete part number

MS90728-3 is a 1/4-20 reference with a 0.500-inch under-head length. MS90728-109 is a 1/2-13 reference with a 1.000-inch under-head length. Use the full series and dash number when ordering.

// MATERIAL AND CONFIGURATION

Preserve the finish and locking requirement

The reviewed MS90728G reference specifies alloy steel, Grade 8, with zinc coating. Earlier issues used cadmium plating; retain the coating and specification issue called out by your drawing.

The table lists plain screws. The reviewed part-number requirements use an L after the dash number for a self-locking element. Preserve that suffix and the locking requirement when applicable; a plain screw and a locking configuration are separate selections.
