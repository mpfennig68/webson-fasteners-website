// PART IDENTIFICATION

Identify the nut family

MS35650 covers plain hexagon machine-screw nuts with UNF-2B internal threads. This selection includes 50 material and finish configurations from 0-80 through 5/8-18. The dimensional table uses MS35650G Amendment 1, which replaces the original Table I.

// ORDERING EXAMPLES

Read the complete part number

MS35650-322 is a 2-64 carbon-steel nut with cadmium plating; MS35650-324 is passivated CRES. MS35650-325B identifies brass with black oxide, while MS35650-325T identifies tin-plated brass. A 4-48 thread belongs to this fine-thread family; it must not be confused with 4-40.

// MATERIAL AND FINISH

Retain the material and finish requirement

The selected carbon-steel dash numbers distinguish cadmium plating from phosphate coating; neither uses an added finish letter. The CRES rows are passivated. Brass rows use B for black oxide or T for tin plating. Other configurations in the standard are outside this selection. Preserve all finish letters instead of reducing the order to a bare dash number.

// FAMILY COMPARISON

Compare related nut families

MS35649 is the coarse-thread machine-screw nut family. MS51968 is a finished hex nut family with separate grade and thickness requirements. The amended MS35650 width limits must be checked within this issue; they should not be copied from the coarse-thread table.
