// PART IDENTIFICATION

A plain nut with a small-pattern hex

NAS671 covers small-pattern, nonstructural plain hex nuts. It is a nonlocking family: the series does not identify an all-metal or insert-type self-locking nut. The smaller hex envelope is part of the requirement, along with the thread and material.

Use the complete drawing callout when sourcing a replacement. A standard commercial hex nut with the same thread may have a different width or height.

// PART-NUMBER EXAMPLES

Read the material and size together

In the selected NAS671 references, a hyphen before the size identifies cadmium-plated carbon steel; C identifies passivated corrosion-resistant steel. NAS671-4 and NAS671C4 share the 4-40 thread reference but identify different material and finish requirements.

NAS671C10 is a 10-32 selection, while NAS671C2 is 2-56. Keep the full number rather than applying another nut family’s size-code rules.
