// PART IDENTIFICATION

External E-type retaining rings

MS16633 identifies reduced-section external E retaining rings. The ring seats in a shaft groove to retain a component axially.

The shaft diameter, groove geometry and retained-part geometry work together in selecting the required ring.

// SIZE SELECTION

A shaft reference is different from a free ring diameter

MS16633-4006 references a 0.062-inch shaft, while MS16633-4009 references a 0.094-inch shaft. The free ring opening and groove diameter have separate dimensions.

Use the specified groove diameter, width and corner geometry when reviewing the application.

// MATERIAL IDENTIFICATION

The dash number carries the material group

MS16633-1014 is a cadmium-plated carbon spring steel selection. The selected -4006, -4009 and -4018 entries are passivated corrosion-resistant steel.

Retain the full dash number when ordering so the required size, material and finish remain together.
