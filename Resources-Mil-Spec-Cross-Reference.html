// IMPORTANT DISTINCTION

A changed standard name can leave the part number unchanged

MS20426 moved to the successor document NASM20426 with part identification numbers unchanged. This is why simply replacing the MS prefix with NASM can create an incorrect ordering number.

// HOW TO INTERPRET A RESULT

Document relationship, mapped part or candidate alternate?

Three cross-reference relationship types
ItemReference
Document successionAn official record names the replacement standard.
Full part-number mappingA complete-designation mapping must be reviewed with its applicable notes.
Candidate alternateA possible substitute still requires the applicable engineering and quality review.

Every relationship in the table above is a document-level finding. It is not a list of commercial interchangeables.
