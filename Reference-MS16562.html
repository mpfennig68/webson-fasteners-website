// PIN TYPES

Identify the pin construction

MS16562 refers to slotted tubular spring pins. The slot and spring section distinguish the family from solid dowels. A drawing can also control the mating hole, installed fit, material and treatment.

// STANDARD REFERENCE

Applicable reference

NASM16562 is an active standard for slotted tubular spring pins. Include the exact drawing callout and issue when asking Webson to review a legacy MS16562 requirement.

// ORDERING DETAILS

What to measure

Record nominal pin diameter, free-state diameter limits where specified, length and the mating-hole requirement. The free pin diameter is not necessarily the same as the hole diameter. Use the specified standard for the relationship.
