All dimensions are in inches. Length preserves printed decimal values such as 0.188 and 0.312; the adjacent ± value is the drawing’s length tolerance. Point values are minimum–maximum limits. J is the drawing’s nominal socket width across flats, not a measured acceptance range.

C applies to the plain cup profile. The reviewed drawing also permits other cup forms with separate C1, C2 and S requirements. The series and these C limits alone do not identify a knurled, hexagon, small-cup or other optional point form; include any specified point-form requirement in the inquiry.

// MEASUREMENT GUIDE

Measure length and point geometry

L is overall screw length from the socket end to the point end. C in the table identifies the diameter of the plain cup profile. The recessed point and socket recess are different features; socket size is listed separately as J.

A cup-point designation does not establish a particular optional knurl, cup form, tightening torque or mating-surface suitability. Follow the assembly drawing for those requirements.

// ORDERING DETAILS

Read the dash number and locking requirement

MS51963-51 identifies a plain 10-24 cup-point screw with 0.500-inch length. MS51963-67 is a plain 1/4-20 screw with the same length. The reviewed issue also lists separate self-locking dash numbers for some sizes; those are outside this selected table.

The reviewed alloy steel requirement specifies Rockwell C45–53 and cadmium plating. A stainless screw with a similar nominal size has a different material and finish requirement.
