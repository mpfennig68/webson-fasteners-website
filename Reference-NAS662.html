// LENGTH CONVENTION

Overall length includes the countersunk head

For these flat-head screws, nominal length includes the head. NAS662C2R2 is a 2-56 by 1/8-inch selection; NAS662C2R9 is a 2-56 by 9/16-inch selection.

// LOCKING CONFIGURATION

Keep the locking identifier in the callout

NAS662C2LPR3 and NAS662C2R3 share a 2-56 thread and 3/16-inch nominal length. The LPR designation retains the patch-type locking configuration and cross-recessed drive.

NAS662C0LPR3 uses a 0-80 thread. Preserve the complete size and locking designation when ordering.
