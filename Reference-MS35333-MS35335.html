// PART IDENTIFICATION

Internal and external tooth configurations

MS35333 identifies internal-tooth lock washers. MS35335 identifies external-tooth lock washers. Retain the specified tooth location and contact geometry when sourcing the washer.

// SIZE AND MATERIAL

Read the family and dash number together

MS35333-36 and MS35335-57 both reference #4 fasteners, with different tooth configurations and material groups. The selected MS35333 entries are carbon steel; the selected MS35335 entries are passivated corrosion-resistant steel.

The internal-tooth table gives nominal identification dimensions. The external-tooth table gives dimension limits. Drawing requirements govern acceptance.
