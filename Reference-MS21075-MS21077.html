// PART IDENTIFICATION

Two floating nutplate families

MS21075 identifies low-height, reduced-rivet-spacing steel floating nutplates. MS21077 identifies two-lug floating nutplates with nonmetallic-insert locking construction.

Mounting geometry, nut height and locking construction remain part of the complete requirement.

// CODE IDENTIFICATION

Retain L and N in the MS21075 designation

L identifies dry-film lubricant in the selected MS21075 entries. N identifies the configuration without eyelets. MS21075L3N and MS21075-3N share a 10-32 thread while retaining different lubrication callouts.

The selected non-dry-film entries are cadmium-plated steel. Keep the required coating with the complete specification callout for dry-film-lubricated versions.
