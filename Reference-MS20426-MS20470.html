// LENGTH AND FINISH

Keep the length convention with the head style

MS20426 countersunk-rivet length includes the head. MS20470 universal-head length is measured beneath the head. Neither measure is the grip-range convention used for a blind rivet.

For the selected aluminum entries, material code A identifies 1100 and AD identifies 2117. A terminal A identifies clear anodize; it serves a different role from an A material code. Unsuffixed selected entries use chemical surface treatment.

The stocked MS20426AD3-5.5 ordering notation is retained. Confirm its complete drawing designation and required length with Webson.

// HEAD GEOMETRY

Start with the installed head

MS20426 identifies a 100-degree countersunk precision-head solid-rivet family. MS20470 is a universal-head solid-rivet family. The head shape and required seat differ, so diameter and length alone do not establish an alternate.

// DOCUMENT AND PART NUMBER

An example of unchanged part numbers

MS20426 has the successor document NASM20426, with the original part identification numbers retained. A NASM document title therefore does not mean an MS part number must be renamed by changing its prefix.
