// PART-NUMBER EXAMPLES

Separate the locking and finish identifiers

In the selected references, L before the length code identifies the screw-locking version. NAS1130-06-15 is free-running; NAS1130-06L15 is screw-locking. Both use 6-32 threads and 1.5D nominal installed length.

Terminal P identifies cadmium plating and D identifies dry-film lubricant. Keep their position and meaning separate from the L locking identifier.

// SUPPLY FORMAT

Confirm the supply format

The stocked NAS1130-06-10DSF entry retains a supplier ordering identifier for a dry-film-lubricated, strip-fed selection. SF is a supply-format identifier, not a separate size code in the standard NAS designation. Confirm the required manufacturer and bulk or strip-feed format with your inquiry.
